# UNITEAPP Android

Android-приложение для объединения устройств в виртуальную локальную сеть.

## Функции

- Подключение к серверу UNITEAPP по IP-адресу
- Создание виртуального сетевого интерфейса через Android VPNService
- Обмен IP-пакетами между подключёнными устройствами
- Поддержка broadcast для обнаружения в LAN-играх
- Автоматический keepalive и переподключение
- Список подключённых пользователей

## Использование

1. Запустите UNITEAPP сервер на VPS
2. Откройте приложение
3. Введите IP-адрес сервера
4. Нажмите «Connect»
5. Разрешите VPN-подключение
6. Готово — ваши устройства в одной виртуальной сети!

## Сборка

```bash
./gradlew assembleDebug
```

APK будет в `app/build/outputs/apk/debug/`.

## Требования

- Android 7.0+ (API 24)
- Kotlin 1.9+
- Gradle 8.5+
